# Security policy

## Supported versions

Security fixes apply to the **latest** **[kpm-selfhosted](https://github.com/hrodrig/kpm-selfhosted)** **`main`** / tagged release of deployment manifests, in combination with supported **[kpm](https://github.com/hrodrig/kpm)** application releases.

## Reporting a vulnerability

Please report security vulnerabilities for the **kpm** project (including deployment docs in this repo) via **[GitHub private vulnerability reporting](https://github.com/hrodrig/kpm-selfhosted/security/advisories/new)** on **kpm-selfhosted**, or the equivalent on **kpm** if the issue is application-only — whichever matches the code you are reporting against.

Do not open public issues for undisclosed security vulnerabilities.
