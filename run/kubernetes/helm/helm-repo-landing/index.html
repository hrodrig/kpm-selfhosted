kpm Helm charts

Helm repository for kpm-selfhosted. The chart packages the in-cluster sampler. The application image is kpm. 

helm repo add kpm https://hrodrig.github.io/kpm-selfhosted/
helm repo update
helm install kpm kpm/kpm --namespace kpm --create-namespace \
  --set secrets.existingSecret=kpm-secrets

Chart index: index.yaml.
